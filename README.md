# GrantFit public research demo

This static demo uses one closed official Daegu announcement and explicitly fictional organization data. It replays a preserved real AI extraction response or a separately labeled fixed fixture. It does not perform new AI calls, accept real organization information, or determine eligibility/selection.

The AI-authored reference draft is not a human-verified or independent gold standard. The real extraction produced zero executable automatic comparisons. Fixture mode demonstrates one narrow location comparison only.

Hosting: GitHub Pages. No API key, account credential, local user path or private document is included. No application-side analytics, login, payment or form submission is used. GitHub may retain security access logs under its own policies.

Official source: https://dgse.kr/page/cop/bbs/articleDetail.do?bbsId=BBSMSTR_000000000178&bbsTyCode=BBST02&menuId=102010000&nttId=11604

Source publisher: Daegu Social Economy Support Center. Posted 2025-05-12. Application closed 2025-05-23. Checked 2026-10-21. Only the main announcement PDF was reviewed; application HWP and reference report were not reviewed.

This is a non-commercial project review prototype, not the publisher's official service or a production SaaS.
